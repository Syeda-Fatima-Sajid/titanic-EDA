# Titanic Dataset - Exploratory Data Analysis (EDA) & Modeling

This project performs a comprehensive Exploratory Data Analysis (EDA) on the classic Titanic dataset, followed by feature engineering, data preprocessing, and building a Random Forest classification model to predict passenger survival.

## 📊 Sections Covered

1. **Data Loading & Cleaning**
   - Handling missing values
   - Basic data inspection

2. **Exploratory Data Analysis**
   - Visualizations to understand distributions and relationships
   - Survival analysis based on features like gender, age, class, and family size

3. **Feature Engineering & Statistical Testing**
   - Creation of new features (e.g., FamilySize, Title extraction)
   - Hypothesis testing for feature selection

4. **Encoding & Correlation Analysis**
   - One-hot encoding for categorical variables
   - Correlation heatmaps

5. **Modeling with Random Forest**
   - Baseline model with train/validation split
   - Cross-validation for better performance assessment

6. **Evaluation**
   - Confusion matrix
   - ROC AUC score

## 🛠️ Technologies Used

- Python (Jupyter Notebook)
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
